### Sobre P2-5: ¿alcanza dejarlo como coordinación?

Sí, y el riesgo es menor de lo que dije en la vuelta 1. La skill de hoy **no usa cualquier terminal**: usa `supcoflow` sólo si `describe` dice `"version":"0.8.1"` y si no corre `npx -y supcoflow@0.8.1`, «never `@latest`» (`skills/supcoflow/SKILL.md:19-22` en `main` `40fa632`). Así que aunque la 0.9.0 apareciera en npm, la skill de hoy seguiría corriendo la 0.8.1 y nunca vería «N of 7». El choque recién aparece cuando una skill fije la 0.9.0, y esa es justo la skill de T9, que ya tiene que mirar `instalacion.ok` / `listo` / `aviso`.

El orden real es entonces: **la CLI 0.9.0 tiene que estar en npm antes o junto con la skill de T9** (la skill fija una versión que tiene que existir), y la skill de T9 no puede seguir pidiendo «6 of 6». El texto del README (`:245-247`) y del informe de verificación («con el punto 7 en falla [la skill de hoy] frenaría una prueba») exagera un poco el riesgo de publicar la CLI sola, pero la conclusión («sale junto con la skill de T9») es correcta y segura. Ver P3-1 de abajo.

### P3-1 — El informe de verificación quedó con dos datos viejos

- **Arreglo:** corregir esas dos líneas (y, si se quiere, la frase del orden). Sólo documentación.

### P3-2 — El aviso de una `interfaz_propia` a medias habla del widget también dentro de `diagnose`

- `src/api.ts:436`: «…I'm ignoring that part and showing the widget only.» `diagnose` también llama a `leerWidget` con `avisar` (`entorno.ts:538`) para el punto 7. Ahí ese texto sale por stderr aunque no se muestra ningún widget, y puede confundir al agente que lee la salida.
- **Arreglo:** un texto neutro, por ejemplo «The engine described the app's own interface halfway; I'm ignoring that part.», o que `probar` pase su propio `avisar` con otro texto. Impacto bajo: sólo pasa si el motor manda un bloque roto.

### P3-3 — Las rutas aceptan `\`

- `src/api.ts:450,456`: `SIN_ESPACIOS_RAROS` deja pasar `\` y el control de `..` sólo parte por `/`. `node_modules/@supcoflow/chat/..\..\x` pasaría. La CLI nunca abre esas rutas (sólo las muestra y las pasa en el JSON), y el motor es de confianza (URL fija), así que el riesgo es teórico. **Arreglo opcional:** rechazar `\` en `conPrefijo`, que cuesta una condición más.

### P3-4 — El título de un test quedó viejo

- `test/instalacion.test.ts:501`: «v1, sin `version`, …: lo anotado vacío». Desde P3-1 una v1 se lee como widget (y lo prueba el test de `:508`). El cuerpo de `:501` ya no usa `version: 1`, así que sólo el título engaña. **Arreglo:** sacar «v1» del título.
